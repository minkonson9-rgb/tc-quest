# TC QUEST — Instagram 미니 RPG

스마트폰에서 바로 플레이할 수 있는 **단일 HTML 파일** 게임입니다.

## 실행
- `index.html`만 있으면 됩니다. 외부 게임 엔진, CDN, 이미지 파일 다운로드가 필요 없습니다.
- PC: WASD/방향키 이동, J/Space 공격, Shift/K 회피, Q 회복약, I 인벤토리.
- 스마트폰: 화면 하단 조이스틱 / 공격 / 회피 / 회복.
- 몬스터에게서 카케라 3개를 얻은 뒤 북쪽의 보스를 처치하면 엔딩과 TC패스포트 링크가 나옵니다.

## GitHub Pages 배포
1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source: Deploy from a branch**를 선택합니다.
3. **Branch: main / (root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 `https://minkonson9-rgb.github.io/tc-quest/`에 접속합니다.

## 주의
- 인스타그램 릴스 화면 안에서 게임하는 기능이 아니라 **링크를 눌러 인스타그램 인앱 브라우저에서 실행**하는 웹게임입니다.
- 이 버전은 별도 라이브러리 없이 작동하는 경량 실행판입니다. 이전 미리보기 이미지의 외부 에셋 기반 그래픽과는 다릅니다.
- 엔딩의 TC패스포트 링크는 운영팀이 공식 등록주소를 확인한 뒤 홍보용으로 사용하세요.
- 실제 iOS 및 Android의 인스타그램 인앱 브라우저 실기기 검증과 가입 전환 분석 연동은 별도 작업입니다.
