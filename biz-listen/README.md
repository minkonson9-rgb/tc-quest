# KIKU LAB — 비즈니스 일본어 듣기

로그인 없이 사용하는 정적 학습 앱입니다.

## 학습 내용

- 20개 분야, 80개 상황, 160문항: 상대 의도 이해와 알맞은 응답 선택
- 전화, 방문 응대, 일정, 요청, 확인, 보고, 회의, 반대, 거절, 사과, 독촉, 메일, 온라인 회의, 가격, 납기, 인수인계, 면접, 호텔, 관계 형성, 해외 업무
- 일본어 대화 및 응답 음성, 반복·속도 조절, 선택형 자막 힌트
- 정중한 표현·격식 있는 표현·사내 표현 240개, 자리 바꾸기 패턴 80개
- 맞춤 난이도, 오답·힌트 복습, 간격 반복, 즐겨찾기, 학습 통계
- 따라 말하기 및 선택적인 브라우저 내 녹음

## 실행

이 폴더를 HTTP 정적 서버로 제공하면 됩니다. 별도 빌드, 로그인, API 키가 필요하지 않습니다. GitHub Pages의 하위 경로를 지원합니다.

## 음성

일반 예문은 일본어 합성 음성 580개를 16개 MP3 묶음과 타임코드로 제공하므로 일본어 기기 음성 설치가 필요하지 않습니다. 사용자가 새로 편집한 패턴의 음성만 브라우저의 일본어 음성을 사용합니다. 브라우저에 따라 지원 여부가 다르며, 지원하지 않으면 안내합니다.

녹음은 사용자가 권한을 허용한 경우에만 기기 내에서 진행됩니다. 서버에 전송하지 않으며 창을 닫으면 삭제됩니다.

## 기록과 개인정보

학습 기록은 현재 브라우저의 localStorage에 저장합니다. 다른 기기로 옮기려면 설정에서 JSON 백업·복원을 사용하세요. 별도 분석 도구나 사용자 계정은 사용하지 않습니다.

## 학습 범위

문제와 해설은 이 앱을 위해 직접 작성한 예시입니다. 공식 BJT 기출문제나 성적 예측 서비스가 아닙니다. 정답은 제시된 상황과 과제에 대한 답이며 실제 대화에는 다른 자연스러운 표현도 있을 수 있습니다.

경어 개념 참고: [일본 문화청 敬語おもしろ相談室](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/index.html), [敬語の指針](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/keigo_tosin.pdf). 공식 자료의 문제를 복제한 콘텐츠는 아닙니다.

## 말하기 코치

같은 URL의 `#coach`에서 내 문장·전달 의도·상대·상황을 기록하고, 20개 의견 말하기 주제, 처음/다시 말하기 녹음, 꼬리 질문, 최대 100개 개인 연습 노트를 사용할 수 있습니다. 말하기 문장·피드백은 듣기 퀴즈와 별도 localStorage 키를 사용하며 녹음은 IndexedDB에 저장합니다. 녹음은 교정 요청에 첨부하지 않습니다. 받아쓰기는 브라우저의 음성인식 서비스를 사용할 수 있고, 브라우저에 따라 지원하지 않습니다.

**현재 공개 버전은 AI 자동 교정 서비스가 연결되지 않았습니다.** 미연결 상태를 화면에 표시하고 자동 교정 버튼을 비활성화합니다. 랜덤 점수, 규칙 기반 판정, 미리 작성된 결과를 AI 평가처럼 표시하지 않습니다. 현재 연습만 담은 교정 요청 복사 및 외부에서 받은 JSON 피드백 가져오기를 제공합니다. 원문이 다른 피드백은 거부합니다. API 연동 전에도 연습·녹음·기록·백업을 사용할 수 있습니다.

`coach-config.mjs`는 공개 설정만 담습니다. 공급자 API 키나 토큰을 절대 넣지 마세요. 자동 교정을 활성화하려면 인증 및 사용량 제한이 있는 HTTPS 서버를 먼저 배포하고 검증한 후 endpoint와 enabled를 설정해야 합니다. 클라이언트는 현재 연습 한 건만 POST하며 과거 연습이나 ChatGPT 대화는 전송하지 않습니다. 응답은 `{feedback: ...}` 구조이며 `coach-core.mjs`의 validateFeedback으로 검증합니다. 연결되지 않은 서비스의 동작은 검증된 것으로 주장하지 않습니다.

문장·피드백 백업은 코치의 연습 노트에서 별도로 제공하며, 기기 내 녹음은 포함하지 않습니다. 녹음은 연습별 다운로드로 보관할 수 있습니다.
